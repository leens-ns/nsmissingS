남성초등학교 분실물 센터

관리자 화면에서 허용 계정, 장소 빠른 입력, 분실물 정리와 보안 점검을 관리합니다.

분실물 조회 화면 분실물 등록/관리 화면
로그인하지 않은 상태입니다.
비용이 발생하지 않도록 정적 HTML, Firebase Spark 무료 범위, 기존 무료 이미지 업로드 흐름만 사용합니다. Firebase 결제를 켜지 않으면 무료 한도를 넘을 때 과금 대신 서비스가 제한됩니다.

허용 계정 관리

CSV 열은 이메일, 권한, 이름 순서입니다. 권한은 교사 또는 관리자를 입력합니다. 삭제는 이메일 열만 있어도 처리됩니다. 내려받는 양식은 엑셀에서 한글이 깨지지 않도록 저장됩니다.

  • 새 교직원은 이메일을 입력하고 교사/관리자 권한을 선택한 뒤 추가합니다.
  • 여러 계정은 CSV 양식 파일로 일괄 추가하거나 일괄 삭제합니다.
허용 계정 목록을 불러오면 계정 수가 표시됩니다.
관리자로 로그인하면 허용 계정 목록이 표시됩니다.

장소 빠른 입력 관리

교사용 등록 화면의 보관 장소 목록과 습득 장소 빠른 입력 버튼을 관리합니다.

보관 장소

관리자로 로그인하면 보관 장소가 표시됩니다.

습득 장소

관리자로 로그인하면 습득 장소가 표시됩니다.
  • 보관 장소는 등록 화면의 선택 목록에 반영됩니다.
  • 습득 장소는 등록 화면의 빠른 입력 버튼으로 표시됩니다.

분실물 일괄 정리

상태별로 대상을 불러온 뒤 선택 항목을 정리합니다.

일반 항목은 휴지통으로 이동하고, 휴지통 항목만 영구 삭제합니다. 휴지통의 물건은 교사용 화면에서 복구할 수 있습니다.

관리자로 로그인한 뒤 정리 대상을 불러오면 목록이 표시됩니다.
정리 기준 보기
  • 상태를 선택한 뒤 대상 불러오기를 누르면 목록이 표시됩니다.
  • 일반 항목은 휴지통으로 이동되고, 휴지통 상태에서만 영구 삭제됩니다.
  • 학생 조회 화면은 무료 사용량 관리를 위해 보관 중 최대 60개를 기준으로 운영합니다.
보안 점검
  • Firebase 결제 사용 안 함 또는 예산 알림 설정 확인
  • Firebase Auth는 Google 로그인 제공업체만 사용
  • firestore.rules 배포 여부 확인
  • 허용 계정 목록에 퇴직자나 불필요 계정이 없는지 확인
  • 영구 삭제 전 휴지통에서 복구 가능 여부 확인
