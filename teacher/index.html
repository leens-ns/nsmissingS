이용 방법
  • 관리자가 허용한 교직원 계정으로 로그인한 뒤 분실물 목록과 등록 기능을 사용할 수 있습니다.
  • 최초 로그인 또는 개인정보 처리방침 변경 시 한 번 동의하며, 같은 방침에 동의한 기록이 있으면 다시 체크하지 않아도 됩니다.
  • 로그인 상태는 같은 브라우저에 유지되므로 공용 기기에서는 사용을 마친 뒤 반드시 로그아웃합니다.
  • 배포된 HTTPS 주소에서는 관리 앱 설치 버튼을 눌러 교직원용 화면을 앱처럼 사용할 수 있습니다.
  • 검색창과 분류·상태 버튼으로 대상을 좁히고, 검색/필터 지우기로 보관 중 전체 목록으로 돌아갑니다.
  • 분실물 등록은 사진, 이름/설명, 분류, 보관 장소, 습득 장소를 입력한 뒤 확인 창에서 한 번 더 검토합니다. 사진은 등록할 때 자동으로 축소됩니다.
  • 사진과 설명은 학생/학부모용 조회 화면에 공개되므로 학생 얼굴·이름표·이름·연락처가 포함되지 않게 확인합니다.
  • 습득 장소는 자주 쓰는 장소 버튼을 눌러 빠르게 입력할 수 있습니다.
  • 카드를 누르면 상세 정보 확인, 수정, 주인 찾기 완료, 폐기 처리, 휴지통 이동을 할 수 있습니다.
  • 폐기 처리는 물품 등록일로부터 30일이 지난 뒤 사용할 수 있습니다.
  • 학생/학부모용 조회 누락을 막기 위해 보관 중 물품은 최대 60개까지 등록할 수 있습니다. 한도에 도달하면 기존 물품을 먼저 정리합니다.
  • 주인 찾음·폐기 완료 항목은 처리 후 7일이 지나고 교직원용 화면에서 해당 상태 목록을 불러오면 휴지통으로 이동합니다. 휴지통에서는 다른 교직원도 복구할 수 있습니다.
  • 일괄 삭제는 휴지통이 아닌 목록에서는 휴지통 이동으로 처리되고, 휴지통에서는 영구 삭제로 처리됩니다.
  • 주인 찾기 완료 시 학생 이름은 입력하지 않고 학년·반·번호만 입력합니다.
  • 관리자 설정에서는 허용 계정, 장소 빠른 입력, 분실물 일괄 정리와 보안 항목을 관리합니다.

v2.2 업데이트 내용
  • 개인정보 처리방침 동의를 계정별로 기록해 같은 방침에는 반복해서 체크하지 않도록 개선했습니다.
  • 근무가 끝난 교직원 계정은 관리자가 허용 목록에서 삭제하면 즉시 접근이 차단되도록 정리했습니다.
  • 허용 계정 확인과 실제 저장 권한이 같은 기준으로 동작하도록 정리했습니다.
  • 폐기 가능 시점을 등록 후 30일로 통일하고, 완료 항목의 휴지통 이동 기준을 이용 방법에 추가했습니다.
  • 분류·상태·일괄 작업 용어와 오류 안내를 화면 전체에서 더 명확하게 정리했습니다.
  • 수령 학생 정보는 이름 없이 학년·반·번호만 입력하도록 안내를 보완했습니다.
  • 공개되는 사진과 설명에 학생 개인정보를 넣지 않도록 등록 안내를 보완했습니다.
  • 보관 중 물품이 60개를 넘어서 조회 화면에서 누락되지 않도록 등록 한도를 적용했습니다.
v2.1 업데이트 내용
  • 교직원용 등록/관리 화면의 검색, 필터, 등록, 일괄 작업 영역을 기능별로 다시 정리했습니다.
  • 일괄 작업 버튼을 일괄 주인 찾기, 일괄 삭제, 일괄 재등록으로 더 명확하게 표시했습니다.
  • 학생/학부모용 조회 앱과 교직원용 관리 앱이 각각 따로 설치되도록 주소와 앱 설정을 분리했습니다.
  • 관리자 화면의 허용 계정 관리와 분실물 일괄 정리 영역을 더 관리하기 쉽게 보완했습니다.
v2.0 업데이트 내용
  • 허용된 교직원 계정만 등록/관리 화면에 접근할 수 있도록 권한 확인 방식을 보완했습니다.
  • 분실물 등록 창에서 필수 입력 상태, 사진 미리보기, 습득 장소 빠른 입력을 더 알아보기 쉽게 정리했습니다.
  • 보관 중, 주인 찾음, 폐기 완료, 휴지통 상태를 구분하고 선택 항목을 일괄 처리할 수 있게 했습니다.
  • 업데이트 안내는 일주일 동안 표시되며 오늘 하루 보지 않음 또는 다시 보지 않음을 선택할 수 있습니다.
